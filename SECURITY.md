# Security Policy

The UNO Mates project team takes security issues seriously and welcomes feedback from security researchers and the community to keep our players and data safe.

## Supported Versions

Only the latest release / `main` branch receives active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive flaw within UNO Mates (such as authorization bypasses, exposed credentials, or data leak risks):

1. **Do NOT report security vulnerabilities through public GitHub issues, pull requests, or discussions.**
2. Report the vulnerability privately via:
   - **GitHub Security Advisories**: Use the "Report a vulnerability" button under the [Security](https://github.com/0xFaysal/UNO-Mates/security/advisories/new) tab of the repository.
   - **Email**: Contact the maintainer directly at [faysalfahim03@gmail.com](mailto:faysalfahim03@gmail.com) with the subject line `[SECURITY] UNO Mates Vulnerability Report`.

### What to include in your report:

- A description of the vulnerability and its potential impact.
- Clear steps to reproduce the vulnerability (proof of concept script, curl command, or step-by-step description).
- Any details about affected environment or dependencies.
- Suggestions on how to mitigate or remediate the issue, if available.

## Our Commitment

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an initial assessment of the issue and an estimated timeline for resolution.
- Once fixed, we will publish an advisory acknowledging your responsible disclosure (unless you prefer to remain anonymous).

Thank you for helping keep UNO Mates secure!
